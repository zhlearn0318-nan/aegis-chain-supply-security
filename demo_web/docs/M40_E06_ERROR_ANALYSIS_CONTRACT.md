# M40 E06 误报、漏报与典型案例分析合同

## 父结果与边界

E06 只分析 E01 v5 的唯一 validation 锁箱结果，固定系统为 S5。父结果、标签和扫描清单均以 SHA-256 锁定；不重新扫描，不修改规则，不把事后分析当成新的独立验证。

## 样本

- 309 条恶意 ALLOW 中，按主要攻击类别和来源分层、按 `sha256(case_id)` 排序，优先结构家族不重复地抽取 60 条；
- 良性非 ALLOW 只有 54 条，按计划的“不足则全量纳入”规则全部分析；
- 共 114 条，不复制样本凑数。

## 归因量表

每条记录包含：标签与 S5 决策、来源/攻击类别、文本意图、主要命中规则、失败原因、建议处置、最合适的后续机制和证据边界。归因使用固定元数据+文本模式量表，是单标注者诊断，不虚构第二人 Cohen's kappa。

只有至少 5 个同类案例支持的方向才进入规则/模型改进建议；这些建议必须另建开发集和新锁箱验证。

## 完成门

- 114 条全部形成逐样本记录，至少 90% 可归入明确原因；
- 分别输出前 5 类漏报和误报原因；
- 输出不少于 6 个答辩案例，覆盖成功检出、漏报、误报、REVIEW 和 UNKNOWN 边界；
- 保留标签争议、完整包缺失和单标注者限制。
