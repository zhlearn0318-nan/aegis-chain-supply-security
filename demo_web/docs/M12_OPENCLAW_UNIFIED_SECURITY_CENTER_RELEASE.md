# M12 OpenClaw 统一安全中心正式发布说明

> 状态日期：2026-08-30
> 适用分支：`openclaw-final-integration`
> 插件版本：`4.0.0`
> 结论：比赛正式演示版本 `READY`；真实政企生产发布仍为 `NO-GO`

## 1. 发布目标

M10 的五个独立侧边栏入口功能完整，但会挤占 OpenClaw 导航空间，整体观感更像多个工具页面。M12 将它们收敛为一个“Aegis 安全中心”入口，使供应链安全能力以统一产品模块呈现。

## 2. 最终信息架构

```text
OpenClaw 左侧导航
└─ Aegis 安全中心（唯一入口）
   ├─ 总览（默认）
   ├─ 准入扫描
   ├─ 扫描报告
   ├─ 审计记录
   ├─ 规则管理
   └─ MCP 准入
```

“总览”读取真实本机审计库，展示累计准入、允许、阻断、审计链完整性和最近事件。其余五项保留 M11 已验收能力，不改变后端安全决策。

## 3. 安全与兼容设计

- 插件只调用一次 OpenClaw `registerControlUiDescriptor`，稳定沿用原 `admission` ID，因此当前正式控制台链接继续有效。
- 功能切换采用同一 OpenClaw 插件框架内的同层导航，不使用二层 iframe。
- 没有为了合并页面而放宽 `frame-ancestors 'self'`、来源检查、页面令牌或失败关闭策略。
- 五个旧 HTTP 页面保留：外部直接访问时跳转到安全中心相应标签；内部使用显式 `embed=1` 呈现功能页。
- 每个功能页均保留统一六标签导航，用户可随时返回总览。
- 一键安装器验证一个安全中心和五个功能视图，共六条 HTTP 200 路由，并在回执记录 `control_ui_sidebar_entries=1`。

## 4. 本阶段修复的既有缺陷

全模块浏览器切换验收发现规则页“清空”按钮的 DOM ID `reset` 会覆盖表单原生 `reset()` 方法，产生 `form.reset is not a function`。按钮已改为 `reset-button`，并增加专门回归测试。

## 6. 正式演示入口

```text
http://127.0.0.1:18789/plugin?plugin=aegis-admission-ui&id=admission
```

建议现场顺序：总览 → 准入扫描安全 Skill → 扫描报告 → 审计记录 → 准入扫描恶意 Skill → 规则管理 → MCP 准入。

## 7. 发布边界

本次完成的是比赛正式版本的信息架构和本机工程验收。第二台洁净 Windows/真实 VM、SSO/RBAC、审批流、外部 WORM/SIEM、多实例高可用以及专用恶意代码隔离仍未完成，因此生产判断不变。
