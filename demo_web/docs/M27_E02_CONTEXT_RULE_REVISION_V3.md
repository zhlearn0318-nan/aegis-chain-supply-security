# M27 E02 条件触发语境规则 v3 修订说明

## 否决依据

v2 在 MaliciousSkillBench source-disjoint train 7,513 条语义组件回归中，将良性非放行率从 27.55% 降至 1.25%，但恶意非放行召回从 25.88% 降至 3.89%，下降 22.00 个百分点，超过运行前冻结的 2 个百分点上限，因此不得接入正式准入。

## 根因

原规则只读取发现所在的短段落，而产生该发现的语义分析器会在前后 14 行关联条件词和风险动作。攻击样本常把正常的“用户何时调用 Skill”写在 front matter 中，再在相邻段落插入强制预执行、隐蔽脚本或免确认指令。短段落判断错误地割裂了同一检测窗口内的行为链。

## v3 规则

1. 上下文窗口与语义分析器统一为前后 14 行。
2. 仅当窗口能够证明是普通用户意图路由语句，并且不存在强制执行、隐蔽行为、免确认或具体脚本调用标记时，才把条件触发发现降为 INFO。
3. 其他模糊条件一律保留 REVIEW，不以“未证明恶意”等同于“证明安全”。
4. 删除 `AEGIS_CONTEXT_OUTSIDE_DECLARED_CLOSURE` 的宽泛降级逻辑。当前实现没有建立真实调用图，不能仅凭 `SKILL.md` 未点名文件就推断文件不可达。
5. 完整高危原语和数据流规则继续禁止降级。

## 预期边界

v3 优先恢复恶意识别能力。它不会追求把所有正常 Skill 直接放行；剩余 REVIEW 应由其他静态证据、动态隔离运行或人工确认闭环处理。训练集只用于工程修订，不能作为独立盲测成绩。
