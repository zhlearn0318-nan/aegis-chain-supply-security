# M28 E02 条件触发语境规则 v4 修订说明

v3 将训练集恶意非放行召回下降从 22.00 个百分点收窄至 3.04 个百分点，并使良性非放行率从 27.55% 降至 19.07%，但仍未达到“恶意下降不超过 2 个百分点”的冻结门槛。

v4 继续使用相同的冻结输入、指标和 2 个百分点门槛，并新建结果目录，不覆盖 v2/v3。
