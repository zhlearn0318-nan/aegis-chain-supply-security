# M29 E02 完整高危规则保护名修订 v5

## 问题

产品接入后的完整规则注册表测试发现，`PROTECTED_COMPLETE_RULES` 中有 5 个历史旧名，与当前分析器实际输出不一致。这会导致“完整高危链绝不降级”的校验只检查旧名，无法覆盖当前规则。

## 修复

- 用当前实际输出的远程解码执行、粘贴服务载荷执行、嵌入载荷执行、启动项修改规则替换旧名；
- 同时保护凭据外传和敏感数据外传两条完整数据流规则；
- 新增参数化测试，证明这些规则即使位于 `examples/` 目录也不会被降级；
- 将 8 个 F1–F3 上下文解释规则登记到正式规则注册表，规则总数由 138 更新为 146。

## 实验纪律

尽管 v4 已通过三项数值门槛，保护集合的改变属于安全语义变化，因此 v4 不直接作为发布证据。v5 使用相同冻结输入重新运行真实 40 Skill、SkillTrustBench regression600 和 MaliciousSkillBench train 来源分组回归。
