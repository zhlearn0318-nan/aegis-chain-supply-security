# M37 E05 OpenClaw 端到端稳定性与性能实验契约

## 1. 研究问题

验证用户通过 OpenClaw “Aegis 安全中心”执行上传、静态审计、三轮动态审计、准入、安装/阻断、同名确认更新、报告和审计查询时，真实闭环能否稳定达到预期终态并满足现场演示时延。

## 2. 正常场景矩阵

固定 12 个场景并重复 3 轮，共 36 次：

1. 纯指令 ZIP，ALLOW 并首次安装；
2. 纯指令文件夹，ALLOW 并首次安装；
3. Python ZIP，ALLOW 并首次安装；
4. Node 文件夹，ALLOW 并首次安装；
5. Shell ZIP，ALLOW 并首次安装；
6. Python ZIP，动态超时后 REVIEW，不安装；
7. Node 文件夹，动态超时后 REVIEW，不安装；
8. Shell ZIP，动态超时后 REVIEW，不安装；
9. Python 文件夹，诱饵访问后 BLOCK，不安装；
10. Node ZIP，敏感读取/外联尝试后 BLOCK，不安装；
11. Shell 文件夹，Shell 启动后 BLOCK，不安装；
12. Python ZIP，同名 Skill 先安装旧版，再验证未确认不替换、确认后事务更新。

每轮使用唯一的 `aegis-e05-*` 安装名；运行前拒绝覆盖预存目录，运行后只清理本轮精确目标。

## 3. 并发与失败闭锁

- 预先完成上传后，同时提交 1、3、5 个扫描请求，验证全局实际运行数不超过 1、忙碌请求得到明确终态且不会永久停留；
- 分别验证 Docker 不可用、本地模型超时、Cisco 扫描器错误时不得返回 ALLOW；
- 失败注入不得修改正式规则、用户真实 Skill 或 OpenClaw 非测试配置。

## 4. 固定判定门

- 36/36 正常运行达到预期决策族；
- REVIEW/BLOCK/UNKNOWN 安装数为 0；
- 内容哈希变化后成功安装数为 0；
- 扫描结果、审计记录、页面数据接口和 PDF 决策一致率 100%；
- 安装目标、上传会话和容器清理率 100%；
- 完整闭环 P95 小于 60 秒、最大不超过 120 秒；
- 并发 running 最大为 1，永久中间态为 0；
- 三类故障返回 ALLOW 的次数为 0。

## 5. 证据边界

实验直接调用 OpenClaw 插件提供给浏览器页面的同一组 HTTP 路由，不调用旁路后端。浏览器 DOM 呈现由插件 UI 测试单独验证；本实验的计时边界从创建上传会话开始，到扫描、安装/阻断、审计/PDF核验结束。
