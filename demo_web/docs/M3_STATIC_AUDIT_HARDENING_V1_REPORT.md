## 1. 本轮结论

本轮没有扩大静态审计的对外能力范围，而是针对评委复核发现的四个高优先级工程缺口进行加固：MCP 的文字承诺不再等同于可执行边界；`tests/fixtures` 下的安全相关代码不再整目录跳过；ZIP 上传增加累计展开量、压缩比和特殊文件防护；Cisco 原始描述、对象名和代码片段不再进入统一 Finding 或 SQLite。

后端完整测试 `254 passed`；平台固定微用例 `20/20`；120 条可见开发集的样本哈希变化为 0，三组配对评估均未产生 normal 决策升级。七项专项加固门禁全部通过。该结论只支持开发阶段机制与工程健壮性，不代替封存回归集上的最终泛化结论。

## 2. 四项加固

### 2.1 MCP：从“文字声明”升级为“机器可验证边界”

旧逻辑会把描述中的 `within approved workspace root` 或 `allowlist` 等短语当作范围保护证据。工具作者可以只写一句承诺而没有真实约束，导致无根目录文件能力或无限制 URL 能力被错误放行。

新逻辑区分两类输入：用户上传 MCP JSON 内的描述或 `x-aegis-boundary` 都只是被审对象的自声明；只有统一平台调用方通过独立的 `trusted_boundaries` sidecar 传入、且已经与当前制品绑定的策略，才能作为边界证据。sidecar 还必须满足：

- `enforced_by` 明确为 `platform_gateway` 或 `mcp_server`；
- 文件系统边界含非空 `roots` 且 `deny_unlisted=true`；
- 网络边界含精确 `allowed_hosts`、仅允许 `https` 且 `deny_unlisted=true`；
- 拒绝通配符、路径上跳和控制字符。

自然语言范围声明和上传包内的机器字段都会保留为解释证据，但只能得到 `MEDIUM/REVIEW`，不能单独证明 ALLOW。当前上传接口不接收可信 sidecar，因此用户不能通过自带字段获得 ALLOW；该参数只留给后续统一平台在受信任调用路径上注入。固定平台用例同时验证文字承诺、上传字段和可信 sidecar，结果为 `20/20`。

### 2.2 Skill：取消 `tests/fixtures` 整目录静默跳过

测试、样例和 fixture 代码可能被打包发布，也可能包含可复制到生产的危险逻辑。旧版三个决策型分析器直接跳过这些路径，形成可预测的检测盲区。

新逻辑对这些路径照常分析。若命中敏感数据外发、不可信输入执行或政企危险控制，则统一降为 `MEDIUM/REVIEW`，并添加 `test_context_unverified_reachability`，表示“发现了风险机制，但仅凭静态路径无法证明生产可达”。生产路径原有严重度保持不变。

这样既消除了静默盲区，也避免把安全测试中的攻击样例直接判为生产攻击。专项门禁验证三个规则族都能产出可复核证据。

### 2.3 ZIP：增加压缩炸弹与特殊文件防护

旧版主要检查路径穿越、成员数量和单文件大小，缺少累计展开量及异常压缩比约束。攻击者可用多个未超单文件上限的成员耗尽磁盘或处理时间。

新逻辑增加：

- 单文件展开上限 15 MiB；
- 整包累计声明/实际展开上限 50 MiB；
- 最大压缩比 200:1；
- 拒绝加密成员、符号链接、设备和其他特殊文件；
- 拒绝重复/大小写冲突目标以及文件—目录冲突；
- 使用 64 KiB 分块手动复制，并在实际字节超限时删除不完整成员。

专项测试分别验证累计展开量和异常压缩比均会被拒绝，正常 ZIP 行为保持通过。

### 2.4 Finding：厂商原始内容最小化留存

Cisco 报告可能包含 Skill 名称、MCP 对象名、描述、威胁摘要或代码片段；这些内容可能携带政企内部接口、项目名或凭据。旧归一化过程会把部分原始文本写入 Finding，随后进入 SQLite 和导出结果。

新逻辑仅保留：

- 固定的通用标题、描述和整改建议；
- 稳定的脱敏对象标识；
- 厂商信号类别；
- 原始证据的 SHA-256，用于同一证据的完整性核对；
- `raw_content_retained=false` 明示最小留存策略。

Finding ID 改为基于规范化证据确定性生成。含秘密标记的 Skill/MCP 模拟报告经过归一化后，原始名称、描述和片段均不存在于序列化 Finding 中。

## 4. 证据边界

本轮能够证明：四个已知工程缺口已由代码、反例测试和冻结门禁共同封闭；在120条可见开发集上没有观察到 normal 决策回退；旧样本文件哈希未变化。

600 条回归集仍作为独立“期末考试卷”封存。最终只在静态规则与策略停止调参后揭盲一次，用于发现过拟合和功能回退。
