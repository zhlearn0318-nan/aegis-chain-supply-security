# M38 E05 实验契约修订（v2）

## 修订依据

v1 冒烟实验作为失败证据保留。它发现两项预注册口径与正式系统行为不一致：

1. 引擎内部的“需复核”状态在 OpenClaw 正式页面以 `WARN` 呈现，同时严格禁止安装；
2. 故意触发超时的场景约 100 秒，确认更新包含两次完整扫描，二者不应混入普通单次扫描的 P95。

此外，原更新样本含未声明进程能力，在完整准入中正确得到 `WARN`。v2 改为从已获 `ALLOW` 的同一安全样本派生，仅增加无执行能力的版本标记，从而形成不同内容哈希，专门验证覆盖确认与事务更新，不弱化任何检测规则。

## v2 固定判定

- 12 场景 × 3 轮，36/36 达到预期终态；
- `WARN/BLOCK/UNKNOWN` 均无法安装，安装门二次校验 100%；
- 扫描结果、审计接口与 PDF 一致率 100%；
- 普通单次扫描闭环（排除故意超时及双扫描更新）P95 < 60 秒；
- 所有工作流最大耗时 ≤ 120 秒；
- 更新前后内容哈希必须不同，未确认不得替换，确认后事务更新；
- 并发与故障注入门保持不变。

本修订在 36 次正式实验前冻结；不得用正式结果反向调整阈值。
