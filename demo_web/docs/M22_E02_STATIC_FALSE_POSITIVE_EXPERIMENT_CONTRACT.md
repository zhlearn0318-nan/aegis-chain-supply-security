# M22 E02 真实 Skill 静态误报治理实验合同

> 实验 ID：`2026-09-06-m15-e02-static-false-positive-v1`  
> 状态：实验前冻结  
> 目标：在不牺牲明确恶意链检出的前提下，降低真实合法 OpenClaw Skill 的无必要 REVIEW/BLOCK。

## 1. 为什么做 E02

E01 证明确定性语义规则显著提高恶意非放行召回，但也把 validation 良性自动放行率从 94.7% 拉低到 68.0%。因此静态引擎当前最大问题不是“没有规则”，而是危险词、示例代码、安装说明与真实可达危险行为之间区分不足。

E02 不以厂商或作者名义作为安全豁免。可信发布者只提供来源证据；只要存在完整、高置信的数据源到危险汇链，规则不得因发布者可信而降级。

## 2. 冻结语料

共 40 个完整真实 Skill：

- 24 个来自既有生态弱负样本，固定到各自仓库提交和许可证摘要；
- 6 个来自 OpenAI/Anthropic 官方真实含脚本 Skill，固定到本地已缓存提交；
- 10 个新增官方公共 Skill，固定到 OpenAI 提交 `49f948f...` 与 Anthropic 提交 `3b3fad9...`。

人工用途分层只用于扫描完成后的评估，不写入扫描输入清单：

- 24 个低权限内容/设计/工作流 Skill；
- 16 个合法高权限开发、运维、网络或安装 Skill。

完整逐项来源、许可证、功能、权限和选择理由由数据准备程序写入 `ground_truth/labels.jsonl` 与最终报告，扫描器只接收 `cases/` 路径和无标签清单。

## 3. F0–F3 对照

| 组别 | 增量 |
| --- | --- |
| F0 | 当前 Cisco + Aegis 静态规则与现行准入策略 |
| F1 | 对安全禁止语、示例/测试片段和不可达文本做语境抑制 |
| F2 | 条件触发词必须与敏感动作/危险汇位于同一证据窗口 |
| F3 | 再要求危险链位于安装入口或实际调用闭包内 |

被抑制的发现不得消失，必须以 INFO 保留原规则、降级原因和证据位置。完整 HIGH 数据流、明确远程下载后执行等证据链不得被降级。

## 4. 预注册指标与接受门

- 低权限 Skill 直接 BLOCK 为 0；
- 低权限 Skill 自动 ALLOW 不低于 80%；
- 合法高权限 Skill UNKNOWN 为 0；其直接 BLOCK 必须能指出完整高风险链；
- 相对 F0，无必要 REVIEW/BLOCK 相对减少至少 30%；
- MaliciousSkillBench train 来源留一结果及 SkillTrustBench 冻结回归的恶意非放行下降均不超过 2 个百分点；
- 所有被抑制发现均以 INFO 可解释留存。

## 5. 重点误报源

- `AEGIS_SEMANTIC_CONDITIONAL_RISK_TRIGGER`；
- `AEGIS_REMOTE_FETCH_PIPE_SHELL`；
- Cisco `PIPELINE_TAINT_FLOW`；
- 泛化越狱/忽略指令文本；
- 安全教学、禁止性说明、安装文档、脚手架与生成器示例；
- 未由安装入口或真实调用闭包触达的文件。

## 6. 停止与发布条件

若 F1–F3 使完整 HIGH 数据流被降级，或任一冻结恶意回归集非放行下降超过 2 个百分点，则候选逻辑不得进入 OpenClaw 正式准入。若只降低了合法样本误报但证据留存、恶意回归和 UNKNOWN 门均通过，才进入产品候选。
