## 1. 为什么使用逐来源留一

train 的标签与来源高度耦合：八个来源中只有三个含良性样本，且其中一个来源承载 1,478/1,521 条良性样本。固定种子的三折 `StratifiedGroupKFold` 仍产生一个纯恶意 held-out 折。因此 v3 使用 `LeaveOneGroupOut`，八个来源各自被完整留出一次：

- 每条 train 样本恰好获得一个严格跨来源的 OOF 概率；
- 同一来源不会同时出现在某次拟合与其 held-out 侧；
- C 与阈值只依据八个来源合并后的 OOF 预测选择；
- 逐来源没有良性或恶性分母时，相应指标明确记录为 `null`。

这不会消除数据集的来源—标签混杂，但比随机拆样本更诚实，也比强行声称每折可计算双类指标更可复现。
