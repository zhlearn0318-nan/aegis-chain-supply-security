# M31 E03 动态 0/1/3 轮消融实验合同

> 状态：分析前冻结。输入为 6 个官方真实原始 Skill 与 30 个受控风险孪生，不执行已知恶意第三方 Skill。

## 对照

- D0：当前 E02 F3-v5 静态流水线，不执行容器；
- D1：D0 + 冻结三轮事件流的 `typical` 严格前缀；
- D3：D0 + 同一事件流的 `typical + edge + adversarial` 全部证据。

现有 108 次真实容器脚本调用具有逐事件 `round`、逐轮终态和耗时，因此允许前缀重放。任何逐包详情哈希不一致都停止实验。D0 重新运行当前静态流水线；D1/D3 只重放原始动态证据，不重新执行容器。

## 指标

风险孪生非放行、预期动态规则召回、静态 ALLOW→动态非放行、静态 REVIEW→动态 BLOCK、首次触发轮次、原始脚本动态 ALLOW、P50/P95 总耗时、容器实例数和脚本轮次数分别报告。

D1 归因耗时等于实测三轮容器总耗时减去实测 edge/adversarial 轮耗时；保留相同的容器创建、安全门和清理开销。该值只用于同一运行的开销分解，不能称为独立一轮实测。

## 决策门

D3 相比 D1 新增至少 1 种风险类型或风险召回提高至少 5 个百分点，同时 P95 总耗时不超过 D1 的 2.5 倍，且原始脚本动态 ALLOW、安全门/清理和输入不变均为 100%，则保留三轮默认；否则选择一轮或条件升级。
