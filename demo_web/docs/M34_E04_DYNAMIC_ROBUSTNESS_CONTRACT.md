# M34 E04 动态审计对抗鲁棒性实验契约

## 1. 冻结目的

本契约在查看实验结果前固定 E04 的样本、指标和判定门，用于回答：简单编码、路径拼接、间接调用、落地执行、延迟触发、进程链、分步数据流和失败状态，是否会绕过 OpenClaw Skill 动态准入。

## 2. 成对设计

- Python、Node、Shell 各 8 对，共 24 对、48 个 Skill。
- 每对由一个安全对照和一个受控风险变形组成，只启用该对声明的风险因素。
- 安全对照不是“直接恶意样本”，因此可独立检验误报；风险变形只执行无害命令、读取容器诱饵或尝试被 `network=none` 阻断的连接。
- 不运行真实恶意第三方代码，不读取宿主真实凭据。

八类因素固定为：编码命令、拼接敏感路径、间接子进程别名、临时文件落地执行、第三轮延迟触发、父子进程链、敏感读取后分步外联、超时失败闭锁。

## 3. 固定安全边界

沿用 `aegis-multiruntime-skill-sandbox-v2`：镜像 digest 固定、无网络、根文件系统只读、Skill/工具只读挂载、UID/GID 65532、丢弃全部 capabilities、禁止提权、限制 CPU/内存/PID、三个输入轮次、容器运行后强制清理。每个样本执行前后均比较输入树哈希。

## 4. 判定门

1. 24 个风险变形全部为 REVIEW/BLOCK；
2. 预期风险规则召回不低于 90%；
3. 24 个安全对照全部 ALLOW；
4. 三轮证明、安全门、清理、输入不变率均为 100%；
5. 任何基础设施失败或证据不完整均不得变为 ALLOW；
6. 任一风险变形被 ALLOW，必须冻结为反例，修复后另建版本复测，不覆盖初次结果。

## 5. 解释边界

这是受控最小变形鲁棒性实验，证明常见简单绕过在既定语言探针和容器边界内的可观测性；它不等价于对所有混淆器、原生二进制、内核级行为或未知语言的完整覆盖。
