# M11 OpenClaw 正式 Skill 上传准入设计与验收

> 状态日期：2026-08-30
> 适用分支：`openclaw-final-integration`
> 结论：比赛正式演示版本 `READY`；生产发布仍为 `NO-GO`

## 1. 改造原因

M9 准入页只能运行预置的安全/恶意样本，适合解释技术链路，但不能证明系统能接收参赛现场选择的真实 Skill。M11 将固定样本页替换为正式上传工作流，同时保留失败关闭、原始日志、动态隔离和哈希链审计。

## 2. 用户工作流

1. 在 OpenClaw 左侧进入“Aegis 准入”。
2. 选择一个 `.zip` 压缩包，或选择一个本地 Skill 文件夹。
3. 填写或确认 OpenClaw 安装名称。
4. 点击“上传并开始安全扫描”。
5. 系统完成安全上传、解包、Cisco/Aegis 静态审计和 Docker 隔离试运行。
6. 只有最终结果为 `ALLOW` 且审计哈希链有效，页面才启用“安装到 OpenClaw”。
7. 安装前重新核对上传内容 SHA-256；OpenClaw 原生 `security.installPolicy` 再扫描一次。
8. 如果存在同名 Skill，页面显示“确认更新并替换”；确认后暂存原版本，失败自动恢复。

## 3. 上传与解包边界

| 边界 | 限制 |
| --- | --- |
| ZIP 格式 | 仅 `.zip`；只接受 stored/deflate；不接受加密 ZIP |
| ZIP 上传大小 | 最大 50 MB |
| 解压后/文件夹总量 | 最大 200 MB |
| 文件数量 | 最大 5,000 |
| 单文件大小 | 最大 50 MB |
| 目录结构 | 根目录包含 `SKILL.md`，或额外包含一层顶级目录 |
| 路径安全 | 阻止绝对路径、`..`、反斜杠、控制字符、Windows 保留名、ADS/非法字符、结尾点/空格和大小写冲突 |
| 文件类型 | 阻止 ZIP 符号链接；服务端暂存目录不接受链接/目录联接 |
| 会话 | 128-bit 随机 ID、30 分钟内存会话、最多 10 个会话；Gateway 重启后资格失效并清理孤立目录 |

## 4. 扫描和安装安全合同

- 上传会话写入项目本地 `demo_web/data/openclaw-final/uploads/`，该目录不进入 Git。
- 预处理后计算规范化目录树 SHA-256；扫描资格绑定 `session + target name + source hash`。
- 静态阶段为 Cisco Skill Scanner、Aegis Static 和自定义规则即时融合。
- 静态 `BLOCK/UNKNOWN` 不进入容器，动态执行次数为 0。
- 静态允许后，Docker 使用固定摘要镜像、无网络、只读根文件系统、非 root、capabilities 全部移除、资源上限和执行后清理验证。
- 动态异常、超时、证据不完整或审计写入失败均转换为阻断。
- 静态扫描预算由 12 秒提高至 60 秒，用于覆盖 Windows 冷启动波动；整个上传扫描仍受 180 秒任务上限约束。
- 安装前再次计算源树哈希；随后 OpenClaw 原生安装策略执行第二次静态与动态复扫，防止扫描后替换。

## 5. 同名更新事务

同名 Skill 不会被静默覆盖：

1. 页面先返回正常业务确认状态，不依赖沙箱 iframe 禁止的浏览器弹窗。
2. 用户点击“确认更新并替换”。
3. 服务端再次验证内容哈希。
4. 原目录在同一文件系统内原子重命名为随机备份目录。
5. 调用 OpenClaw 官方 `skills install`。
6. 只有新目录存在、最新审计为 `ALLOW` 且全链有效才删除备份。
7. 任一步失败，删除不完整新目录并恢复原目录。

## 7. 现场演示建议

优先演示三个步骤：

1. 上传安全 ZIP，展示文件数、解压大小、内容指纹、Docker clean 和安装路径。
2. 再上传同名安全文件夹，展示“确认更新并替换”和事务日志。
3. 上传恶意文件夹，展示 `BLOCK`、静态规则、动态未执行和安装按钮禁用。

这样可以同时证明系统支持真实输入、严格准入、动态隔离、更新授权和失败关闭，而不是播放预置结果。

## 8. 未完成的生产能力

- 尚未在第二台洁净 Windows/真实 VM 上完成一键部署全流程；
- 没有多用户 SSO/RBAC、审批流和职责分离；
- 审计链仍是本机 SQLite，未外送 WORM/SIEM；
- 没有多实例高可用和分布式任务队列；
- Docker 沙箱降低风险但不能证明任意未知代码绝对安全；Falco/eBPF 旁证仍未完成。

因此当前结论仍是：比赛现场正式演示版本 `READY`，真实政企生产发布 `NO-GO`。
