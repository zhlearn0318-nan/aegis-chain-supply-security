# M19 E01 静态检测组件消融实验合同 v4

> 状态：运行前冻结  
> 实验编号：`2026-09-06-m15-e01-static-ablation-v4`

## 1. v3 暴露的问题

v3 完成八个逐来源留一折后，在阈值选择阶段发现：`C=0.25` 在冻结的 0.10–0.90 网格内没有任何阈值满足“聚合良性误报率不超过 5%”。这表明来源—标签混杂造成的 OOF 偏移比预期更强。程序在最终拟合和 validation 前失败关闭。

同时，v3 没有在阈值选择前持久化 OOF 概率，导致已经完成的折不能续跑。该负结果保存在 v3 的 `TRAIN_STOP.json`，不覆盖、不删除。

## 2. v4 的两项限定变更

1. 每个 held-out 来源完成后立即保存合同哈希、样本 ID、五个 C 的概率和折元数据；重启时逐项校验后复用。
2. 阈值候选在原 0.10–0.90 网格后增加 0.91–0.99、0.995、0.999 和 1.0。阈值 1.0 是“零模型阳性”的保守退路，用来保证误报门优先于召回，而不是提高成绩。

数据、特征、分类器、C 候选、逐来源留一、S0–S6、validation 单次锁箱、统计方法和最终接受门均不变。阈值仍完全由 train OOF 冻结，validation 不参与选择。

## 3. 解释纪律

若只有极高阈值才能满足 5% OOF 良性误报门，报告必须直接说明轻量模型跨来源校准较差。若 validation 上不能带来至少 8 个百分点恶意非放行增量，或良性放行损失超过门槛，S5 判为不通过，不接入 OpenClaw 正式策略。
