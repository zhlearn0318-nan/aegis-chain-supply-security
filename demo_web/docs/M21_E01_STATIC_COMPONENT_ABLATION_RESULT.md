# M21 E01 静态组件对照与消融实验结果

> 实验：`2026-09-06-m15-e01-static-ablation-v5`  
> 状态：正式完成；validation 完成评测次数为 1  
> 产品决策：轻量模型通过研究接受门，但在 E02 误报治理完成前不直接改变 OpenClaw 正式准入策略

## 1. 实验可信性

- 数据为 MaliciousSkillBench 固定提交 `d4b42ce5766a6e0359c987cf59c1007cb3795a90`；train 7,513 条、validation 835 条。
- train 使用八折逐来源留一生成 OOF 概率，C 和阈值只由 train 选择。
- validation 扫描清单不含标签；静态扫描结果写入并锁定 SHA-256 后，才由 evaluate 命令打开标签文件一次。
- 9 条 validation 文本被主机内容防护阻止精确物化，19 条未获得可索引 Cisco 结果；合计 28 条按 UNKNOWN 失败关闭。
- 没有执行任何数据集脚本。Qwen 和轻量模型只可增加 REVIEW 证据，均不能独立产生 BLOCK。
- validation 扫描前后输入树 SHA-256 均为 `fe7e0b3042ccb67ee35e0c8de9b6c6edf8344a37a406fc6af6a5fb87e252154d`。

## 2. 训练阶段结果

由于标签与来源高度耦合，五折和三折分组方案在运行前检查中均无法保证合理的 held-out 类别覆盖，已分别保留 v1、v2 停止证据。v3 又发现 0.90 及以下阈值无法满足 5% 良性 OOF 误报门。v4 虽完成训练，但训练预检曾解析 validation 标签文件，按程序性要求判无效。v5 使用真正不打开 `ground_truth` 的标签盲预检重新训练。

v5 冻结结果：

- 分类器：word/char TF-IDF + Logistic Regression；
- 选中 `C=2.0`，阈值 `0.99`；
- train 来源留一 OOF 恶意召回 2.27%；
- train 来源留一 OOF 良性误报率 3.81%；
- OOF 平衡准确率 49.23%。

这说明轻量模型在“完全未见来源”上校准较差，不能被描述为强泛化分类器。它在本系统中的角色必须保持为候选 REVIEW 证据。

| 系统 | 组件 | 恶意非放行召回 | 恶意 BLOCK | 良性 ALLOW | 良性 BLOCK | UNKNOWN |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| S0 | Cisco only | 13.5% | 5.3% | 96.4% | 0.0% | 3.4% |
| S1 | S0 + Aegis 确定性规则 | 21.5% | 10.4% | 94.7% | 0.0% | 3.4% |
| S2 | S1 + 能力一致性 | 21.5% | 10.4% | 94.7% | 0.0% | 3.4% |
| S3 | S1 + 确定性语义 | 44.3% | 10.8% | 68.0% | 0.6% | 3.4% |
| S4 | S1 + 能力 + 语义 + Qwen | 44.3% | 10.8% | 68.0% | 0.6% | 3.4% |
| S5 | S4 + 轻量模型 | 53.6% | 10.8% | 68.0% | 0.6% | 3.4% |
| S6 | S5 关闭 Qwen | 53.6% | 10.8% | 68.0% | 0.6% | 3.4% |

关键增量：

- S1 相对 S0：恶意非放行召回增加 7.96 个百分点，95% CI 6.01–10.06；良性 ALLOW 下降 1.78 个百分点。
- S2 相对 S1：最终决策增量为 0。原因是该数据集主要为静态 `SKILL.md` 文本快照，不含能力一致性分析所需的完整脚本树。
- S3 相对 S1：恶意非放行召回增加 22.82 个百分点，但良性 ALLOW 下降 26.63 个百分点；语义规则是当前最大检出增量，也是最大误报来源。
- S4 与 S3 最终决策完全相同。正式扫描前完成 Qwen 预热，19 次真实路由、0 失败，但最终决策增量为 0。
- S5 相对 S4：恶意非放行召回增加 9.31 个百分点，95% CI 7.06–11.56，McNemar 精确检验 `p=4.34e-19`；良性 ALLOW、良性 BLOCK 和 UNKNOWN 均无变化。

## 4. 接受门与工程判断

S5 满足全部预设接受条件：恶意增量超过 8 个百分点且置信区间下界大于 0；良性放行无额外损失；良性直接阻断无增加；UNKNOWN 不增加；输入树不变；validation 只完成一次评测。

但“研究接受门通过”不等于“产品立即启用”：

1. validation 与 train 共享来源，而逐来源留一 OOF 表现很弱；S5 的提升不能外推为对全新生态来源的同等提升。
2. S5 只把 62 条恶意样本从 ALLOW 提升为 REVIEW，未提高 BLOCK 率；它是人工复核辅助，不是阻断器。
3. S4/S5 的良性自动放行率只有 68.0%，不满足通用政企平台的日常可用性要求。
4. Qwen 目前只有运行可靠性证据，没有检测增量证据；默认调用会增加依赖和时延，不应因“用了大模型”而保留。

因此下一步 E02 的优先事项是治理确定性语义规则的安全语境误报，并在真实完整 Skill 上验证；HIGH 完整数据流和明确恶意链不得被降级。
