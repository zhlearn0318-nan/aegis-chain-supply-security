# Aegis Chain 开发排期（2026-08-07 至 2026-08-31）

## 最终目标

在 8 月 31 日前冻结一个可独立运行、也可通过 HTTP 接入统一平台的“智能体组件安全准入网关”。它接收 Skill ZIP、MCP JSON 和依赖清单，输出统一风险证据、`ALLOW/REVIEW/BLOCK/UNKNOWN` 决策及可导出报告。

每天按 2—3 小时安排。完成条件以“有代码、有测试、有结果文件”为准，不以“读完资料”为准。

## 里程碑

### M0：Cisco 基线可复现（已完成，8 月 7 日）

- 固定 Skill Scanner 与 MCP Scanner 的提交和运行环境。
- 真实跑通 Skill、MCP、依赖漏洞三条静态链路。
- 统一 Finding 和四态门禁，扫描失败时返回 `UNKNOWN`。
- 固定机器可读基线和自动测试。

- 把 700 行单文件后端拆成 `adapters / normalizers / policy / storage / api`。
- 给统一 Finding 定义 Pydantic 模型与 `schema_version`。
- 将阈值、禁用能力、敏感数据和允许域名移到 YAML 策略。
- 增加 API 契约、错误码、超时和 20 个以上单元测试。

验收：上传安全/恶意 Skill 和 MCP 样本均能得到可解释、可复现的统一 JSON。
