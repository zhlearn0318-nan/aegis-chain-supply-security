# PLAN：Skill 动态审计 20 样本稳定性回归 v1

## 1. 实验登记

- run id：`2026-08-27-skill-dynamic-regression20-v1`
- 实验层级：`auxiliary/dev-regression`
- 接受基线：`2026-08-27-skill-dynamic-sandbox-real-v2`（5 类样本 × 3 轮，15/15 通过）
- 固定随机种子：`20260827`（当前样本为确定性脚本，种子用于保持实验元数据可复现）
- 研究问题：当前动态审计能否在真实 Docker 隔离环境中，对 20 个覆盖八类行为的自建 Skill 连续 3 轮给出稳定、正确且可解释的结果？

## 2. 预注册假设

- 零假设 H0：60 次执行中至少出现一次预期决策/规则不匹配、危险漏报、良性误报、遥测不完整、清理失败、容器残留或跨轮不稳定。
- 备择假设 H1：60 次执行全部符合预期决策与必需规则，三轮结果稳定，且上述负向指标全部为 0。

## 3. 样本矩阵

| 行为族 | 数量 | 目标 |
| --- | ---: | --- |
| 良性对照 | 4 | 验证纯计算、工作区写入、回环请求和空操作不会被误阻断 |
| 进程执行 | 4 | 覆盖 Shell、传输工具、普通子进程和 `os.system` |
| 外部网络 | 3 | 覆盖直接 IP、DNS、运行时编码拼接地址 |
| 诱饵与编码外传 | 4 | 覆盖只读、原文、Base64、十六进制外传 |
| 敏感路径 | 2 | 覆盖系统身份文件与 SSH 凭据路径 |
| 原生/动态加载 | 2 | 覆盖不同 `ctypes` 原生库加载形式 |
| 资源滥用 | 1 | 覆盖运行超时 |
| 合计 | 20 | 每个样本运行 3 轮，共 60 次容器执行 |

## 4. 固定安全合同

- 使用本地已有、固定 digest 的 Python 镜像，`pull=never`；
- `network=none`、非 root、只读根文件系统、移除全部 capabilities；
- `no-new-privileges`，CPU、内存和 PID 数量受限；
- Skill 和审计工具只读挂载，临时工作区使用受限 tmpfs；
- 每次创建后检查容器实际配置，任一门不符则不启动；
- 每次执行后删除容器，整轮结束后按后端标签查询残留；
- 不使用 GPU、云服务、互联网和第三方恶意样本。

## 5. 接受标准

- 样本清单、文件集合与 SHA-256 全部锁定且通过校验；
- 20 个场景 × 3 轮 = 60 次执行全部完成；
- 决策正确 60/60，必需规则召回 100%；
- 危险漏报、良性误报、遥测缺失、清理失败、容器残留均为 0；
- 同一样本三轮的决策和规则集合完全一致；
- 完整保存命令、环境、镜像、配置、逐样本结果和限制边界。

## 6. 分档结论与停止条件

- minimum：60 次执行完成，失败项被完整保留，可定位规则或基础设施缺口；
- solid：达到全部接受标准；
- maximum：在 solid 基础上补齐按行为族的覆盖率、时延分布和规则命中稳定性报告。
- 若样本需要开放外网、宿主机敏感目录、特权容器或执行未经评估的第三方代码，立即停止，不为追求指标放宽隔离合同。

## 7. 结论边界

本实验是受控自建样本的开发回归，不是现实世界第三方 Skill 的泛化率测评。Python audit hook 是可解释证据采集层，不是不可绕过的内核安全边界；Docker Desktop/WSL2 也不等同于专用恶意代码分析虚拟机。
