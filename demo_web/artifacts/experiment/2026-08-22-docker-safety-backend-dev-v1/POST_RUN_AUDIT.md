# D2 v1 运行后复核

v1 的 40/40 镜像、配置和运行时安全门真实通过，容器成功清理，隔离机制未受影响。

运行后复核发现报告字段 `engine.api_version` 为字符串 `None`。原因是 Docker CLI JSON 使用 `ApiVersion`，代码只读取 `APIVersion`。该问题不影响镜像身份、容器配置或运行行为，但会使环境清单不准确，因此 v1 保留为校准父运行，不作为最终接受结果。

v2 修正 API 字段兼容，并增加“容器启动超时后仍使用本轮精确 container ID 强制清理，再验证容器不存在”的模拟测试。安全参数、镜像、fixture、指标合同和静态决策不变。
